🔀 SPA Router Logic

Hash-based routing in router.js — listens for hash changes, fetches templates, injects HTML:

flowchart TD HASH["window.location.hash changes"] --> PARSE["Parse hash + query params"] PARSE --> LOOKUP["Lookup route in routes map"] LOOKUP --> FETCH["fetch template.html"] FETCH --> INJECT["#mainbody.innerHTML = html"] INJECT --> ROUTE{"Which route?"} ROUTE -->|"#home"| R1["renderHome"] ROUTE -->|"#DBhomePage"| R2["fetchDBInfo\nGET /db_info"] ROUTE -->|"#DBcalander"| R3["fetchTradingDays year\n+ renderDBCalendar"] ROUTE -->|"#OptionCharAnalysis"| R4["Load analysis data\n+ render charts"] R4 --> R4A["GET /analysis_details?date=\npopulate option chain"] R4A --> R4B["loadNiftyChart date\nGET /chart_data?type=nifty"] R4A --> R4C["loadOptionChart CE\nGET /chart_data?type=option"] R4A --> R4D["loadOptionChart PE\nGET /chart_data?type=option"]

🔌 Server API Endpoints

server.py — Python HTTP server with CORS support and SQLite queries:

Endpoint Params Returns
/db_info — Total entries, indexes, strikes, dates, expiries
/analysis_details date ATM strike, 7 strikes array, CE/PE presence map
/chart_data date, type, strike?, option_type? Array of OHLCV candles (+ delta/gamma for options)
/day_range date Nifty min/max, strike min/max, data presence flags
/api/* — Proxy to api.dhan.co (for live trading)

💾 Database Summary

option_master

540,215 rows
  • Indexes: NIFTY, SENSEX, BANKNIFTY
  • Date range: 2025-11-13 → 2026-06-25
  • 74 unique trading days
  • 154 unique strikes (22,750 → 85,800)
  • Option types: CE, PE
  • Columns: OHLCV + delta + gamma

nifty_50_holc

206,397 rows
  • Date range: 2024-01-01 → 2026-03-20
  • 553 unique trading days
  • Minute-level OHLCV data
  • Nifty 50 index only
