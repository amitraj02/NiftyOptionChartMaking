Code Help and Reference Dictionary

This file documents all files, functions, HTML tags, variables, and CSS properties utilized inside the Nifty Option Chart Making project, with a single-line simple explanation for each.

1. Project Files & Databases

Item Name Type Explanation
index.html HTML File Main entry point container loaded by the browser, holding navigation headers and scripts.
home.html HTML Template Home view displaying credentials metadata and user stock holdings fetched from the broker.
basicStructure.html HTML Template Displays the Nifty, Call, and Put options charts along with the symmetrical 3x7 option chain grid.
DBhomePage.html HTML Template Tab view displaying select options for trading years and details of database records.
DBcalander.html HTML Template Template hosting the dynamically generated 12-month calendar grid view.
LocalDatabase.db SQLite Database Database holding historical option chain rates and underling index values.
server.py Python Server Handles local file serving, CORS credentials forwarding, and local SQLite data queries.
router.js JavaScript Route Loader Intercepts browser hashes to fetch and inject templates, and runs page-specific initialization scripts.
clientInfo.js JavaScript Controller Manages credentials validation and renders stocks holdings table on the Home page.

2. JavaScript Functions

Item Name Type Explanation
updateClock() JS Function Updates the navigation header time panel with the client's current local time string.
handleLocation() JS Function Parses the URL hash and dynamic query parameters to render the matching page template.
fetchTradingDays(year) JS Function Loads the specified year's Nifty CSV file to populate a lookup Set of active trading dates.
renderDBCalendar(year, tradingDays) JS Function Dynamically builds calendar card days with classes indicating weekends, trading days, and market holidays.
fetchDBInfo() JS Function Fetches database counts and unique value ranges from the backend server to populate the dashboard.
openDBcalander(year) JS Function Global helper modifying browser URL hash parameters to trigger calendar views.
fetchDhanUserProfile(clientId, accessToken) JS Function Makes a profile query request to the broker API endpoints.
fetchDhanHoldings(clientId, accessToken) JS Function Makes a stock portfolio holdings query request to the broker API endpoints.
renderHome() JS Function Fetches local config file env.txt and inserts broker account portfolio stock details on the home screen.
resampleCandles() JS Function Resamples fetched HOLC candles into 1m, 3m, or 5m intervals for the index chart panel.
loadIndexChart() JS Function Loads the selected date's index candles into the analysis page chart area and respects the chosen time interval.
loadOptionChart() JS Function Loads a selected strike's CE/PE chart when the user clicks the option chain cells.

3. Python Backend Functions

Item Name Type Explanation
get_db_info() Python Function Queries SQLite database schema to count entries, list unique strikes, indexes, and expiries.
get_analysis_details() Python Function Returns index name, day range, ATM-based strike list, and option presence data for the selected date from the local SQLite database.
do_GET() Python Method Handles incoming HTTP GET requests for static files, /db_info stats, or proxies /api/ calls.
do_POST() Python Method Handles incoming HTTP POST requests, proxying them to Dhan credentials endpoints.
handle_proxy(target_url, method) Python Function Forwards local credentials requests to dhan.co servers and passes back responses.
send_cors_headers(origin) Python Function Appends CORS access control policy details on responses to allow local scripting.
load_credentials() Python Function Extracts access keys and user codes from env config texts.
get_holdings(dhan) Python Function Downloads stocks details from broker via SDK and prints them to terminal.

4. Essential Variables & Constants

Item Name Type Explanation
routes JS Object Dictionary mapping browser hash paths to matching template file names.
PORT Python Int Static variable configuring the local web server port number (8000).
DHAN_CLIENT_ID String Dhan broker account client identification key.
DHAN_ACCESS_TOKEN String Authentication JWT security token for Dhan HQ API.
monthNames JS Array String list of months names used to render headings on calendar cards.
daysOfWeek JS Array String list containing initials of weekdays to build grid headers.

5. HTML Tags Used in Layouts

Item Name Type Explanation
<div> Block Tag Common wrapper tag creating cards, sections, layouts, and division boundaries.
<span> Inline Tag Inline container tag displaying labels, greeks numbers, and metadata badges.
<nav> Structural Tag Organizes nav containers containing links to shift dashboard pages.
<ul> <li> List Tags Wraps individual items forming tabs selectors inside navigation bars.
<a> Anchor Tag Clickable hyperlinks updating window hash states to switch SPA tabs.
<button> Action Tag Interactions trigger that fires functions (like calendar redirects or back controls).
<select> <option> Form Tags Form dropdown selection menus listing script choices.
<label> <input> Form Tags Clickable text labels and checkbox selections to filter trading properties.
<table> <tr> <td> Table Tags Formats data rows, header titles, and stats grids into structured tables.
<h2> <h3> <h4> Semantic Tags Represents headings and section labels of varying size hierarchy.

6. CSS Classes & Layout Styles

Item Name Type Explanation
.option-chain CSS Grid Symmetrical 3x7 layout grid displaying Call, ATM, and Put option parameters.
.chart-section CSS Flexbox Row flexbox container displaying the Nifty index chart and option charts side-by-side.
.calendar-cell CSS Layout Tile representing a calendar day, highlighted with unique state colors.
.cell-dots CSS Layout Horizontal dot row container positioned at the bottom of calendar day cells.
.dot-option CSS Indicator Blue color dot indicator representing presence of options master contracts data.
.dot-nifty CSS Indicator Orange color dot indicator representing presence of underlying Nifty index HOLC data.
OptionCharAnalysis.html HTML Template Layout displaying option chain grids and underlying index and options charts.
/day_range API Endpoint Queries SQLite to return Nifty index price ranges and options strikes coverage details for a given date.
showDayPopup(dateKey) JS Function Constructs and displays a modal popup card with index range metadata when clicking a calendar day.
.popup-overlay CSS Class Z-indexed dark blur background overlay element covering the screen behind active popups.
.popup-card CSS Class Styled card container positioning database range numbers, loader, and jump buttons.
